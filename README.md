# EventHub Playwright Automation

## Purpose
Build real-world QA automation on an event-booking application.

## Project Overview
This project focuses on validating the core user flows of an event-booking platform through automated testing. It combines UI validation for event discovery and booking with API verification using the live backend and Swagger documentation to ensure the application behaves correctly end-to-end.

## Testing Scope
- UI testing: Explore event discovery and booking workflows.
- API testing: Use live APIs and Swagger documentation to identify endpoints and validate responses.

## Technologies and Design Framework
- JavaScript + TypeScript
- Playwright
- POM Design
